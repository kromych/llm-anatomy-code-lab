  python3 -m venv ~/vllm-cpu                      (Python 3.14.8)
  ~/vllm-cpu/bin/pip install uv
  ~/vllm-cpu/bin/uv pip install --python ~/vllm-cpu/bin/python \
    https://github.com/vllm-project/vllm/releases/download/v0.32.0/vllm-0.32.0+cpu-cp38-abi3-manylinux_2_39_x86_64.whl \
    --torch-backend cpu                           (17 s; 152 packages)
The documented URL pattern ends in manylinux_2_34_x86_64.whl; for 0.32.0 that
file does not exist (HTTP 404), and the release ships manylinux_2_39 wheels
for x86_64 and aarch64 and a macosx_11_0_arm64 wheel (30 MB), although the
docs say Apple silicon has no pre-built wheel. The docs list avx512f as
recommended and avx2 as "limited features"; the wheel carries _C, _C_AVX2 and
_C_AVX512 extension modules.
