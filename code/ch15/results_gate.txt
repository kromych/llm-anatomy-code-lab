Each line: the harness, the action, and the first characters of what the
model was told after its one shell command ("exit N:" is the exit code that
Codex reports).  read inside: cat stats.py; read .env: cat .env; read
outside: cat ~/.gate-elsewhere/secret.txt; write inside: echo x >
inside.txt; write outside: echo x > ~/.gate-elsewhere/written.txt;
loopback: curl to the stand-in model's own port.  Codex's sandbox refused
the write outside the workspace ("operation not permitted") and the
connection (curl's exit code 7); everything else ran in every harness.
